# rock — CampusBreak

## Тақырып
Сабақ арасындағы бос уақытта («окнода») студенттерге уақытын тиімді өткізетін жақын маңдағы орынды (тыныш оқу аймағы, коворкинг, қолжетімді асхана, демалыс) жылдам табуға көмектесу.

Мақсатты пайдаланушылар: Университет және колледж студенттері (сабақ арасында 1–2 сағат үзілісі барлар)  
Сұхбатқа: 3–5 студент (өзімнің тобымнан және көрші курстағы таныстар)  
Рөлдер жүйеде: Студент (іздеуші, пікір қалдырушы), Модератор/Админ (орындар базасын басқарушы)  
AI идеясы: Студенттің еркін сұранысын (мысалы: «розеткасы бар тыныш орын», «арзан түскі ас») мәтіннен талдап, жақын маңдағы ең қолайлы локацияны дербес ұсыну  

Бекітілді: 16.11.2026 (оқытушы)

## Жоба туралы

Студенттерге сабақ кестесіндегі 1–2 сағаттық «окно» кезінде кампус маңынан қолайлы орынды (тыныш оқу орны, коворкинг, қолжетімді асхана) жылдам табуға арналған веб-платформа.

## Қалай жұмыс істейді

1. Студент өз қалауын еркін сөйлеммен жазады (мысалы: «розеткасы бар тыныш орын» немесе «арзан түскі ас»).
2. Жүйе (AI көмегімен) сұранысты талдап, жақын маңдағы ең қолайлы 1–3 орынды ұсынады.
3. Студент орынның жағдайын көріп, барады және пікір қалдырады.

## Пайдаланушы рөлдері

- **Студент** — орындарды іздейді, сұраныс жазады, орын карточкаларын қарайды және пікір қалдырады.
- **Модератор/Админ** — жаңа орындарды қосады, мәліметтерді өңдейді және пікірлерді қадағалайды.

## Технологии

- **Backend:** FastAPI
- **Frontend:** Next.js 16
- **База данных:** PostgreSQL, SQLAlchemy 2, Alembic
- **Авторизация:** Keycloak (OIDC)
- **ИИ:** Ollama — локальная языковая модель для генерации тестов
- **Тестирование приложения:** pytest
- **Инфраструктура:** Nginx, Docker Compose
- **Дополнительно:** Redis, RabbitMQ и фоновые задачи

## Архитектура: Қабат картасы (4-сабақ)

Проект строго следует принципу чистой 5-слойной архитектуры:
- **Router (`app/api/v1/routers/`):** Приём HTTP-запросов, проверка ролей (`student`/`teacher`/`admin`), вызов Service, трансляция исключений в HTTP-коды (`Қате→HTTP`). **Никакого SQL в Router!**
- **Schema (`app/schemas/`):** Pydantic DTO (Кіріс → Шығыс).
- **Service (`app/services/`):** Чистая бизнес-логика. **Никаких HTTPException в Service!** Выбрасываются только кастомные доменные исключения.
- **Repository (`app/repositories/`):** Единственная точка работы с базой данных (SQLAlchemy 2).
- **Model (`app/models/`):** Таблицы базы данных (DeclarativeBase).

> **Мызғымас ережелер:**
> 1. Router-де SQL жоқ, service-те HTTPException жоқ.
> 2. Құпиялар тек `.env`-те.

## Запуск проекта

### 1. Настройка окружения
Скопируйте шаблон переменных окружения:
```bash
cp .env.example .env
```

### 2. Запуск контейнеров через Docker Compose
```bash
docker compose up -d --build
```

### 3. Применение миграций базы данных
```bash
docker compose exec backend alembic upgrade head
```

### 4. Загрузка модели в Ollama
```bash
docker compose exec ollama ollama pull llama3:8b
```

### 5. Запуск тестов backend
```bash
docker compose exec backend pytest
```
